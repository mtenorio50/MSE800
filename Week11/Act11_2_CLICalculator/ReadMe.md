## Engineering Calculator CLI

This is a simple command-line engineering calculator built in Python.
It supports basic arithmetic operations (add, subtract, multiply, divide), power, root, and trigonometric functions (sin, cos, tan).

Unit tests are provided using pytest.

How to run the test:

- pip install pytest
- pytest test_calculator.py

# Testing

Automated unit tests were written using pytest to verify the calculator’s functions, including arithmetic, power, roots, and trigonometric operations. The tests cover normal usage, edge cases, and invalid input, ensuring the calculator is reliable and accurate.
